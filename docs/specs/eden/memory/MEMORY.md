## Lessons learned
- The agents repo index is shared by every session: never run a bare `git reset`, `git add -A` or `git commit -a`. Stage and commit only my own paths, in one command (`git commit -- <paths>`).
- Journal times (12 Nov): run `date` (GMT), or decode an org-agent message ULID (the first 10 chars are ms since the epoch), before stamping an entry. Never estimate the time; my guesses drifted 1–2 h ahead of ada's record.
- Validation numbers (12 Nov): compute ranges and counts myself from the results JSON before they go in a report or a row. Check summaries round and drop configurations; four review rounds on #75 were only about numbers.

A pin that departs from either needs its geometry checked first. (12 Nov: 'p-4 below 640' contradicted §Dialog p-6 and clashed with Rowan's header geometry, so I withdrew it.)
