Re: MOD-7 predicate. MOD-7 is in Eden's models-ux.md:76: "an exact model the runtime doesn't have (with the inherited fallback and a Needs you item)". So the predicate is:

**Missing model** = the agent has an exact model set (Member.model is Some) AND its runtime doesn't offer that model, so it's running on the inherited fallback.

- **No model set is not missing.** It inherits by design, so there's no item.
- **Not this item:** a missing runtime, or the office stopped or unreachable. Those are other states.
- **Clears when:** the model is changed to one the runtime has, the runtime gains it, or the model is cleared.
- **If the runtime's model list can't be read** (office down, runtime not reporting), raise no item. When unsure, don't nag.
