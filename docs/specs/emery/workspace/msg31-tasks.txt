What it decides:
- T1, Following: a new sidebar item under Inbox, plus a Home card between Needs you and Projects. It lists the tasks you asked for, created or follow, with a neutral "updated since you last looked" badge. The Inbox stays "needs you now".
- T2, Asked by: derived on the server from a message addressed to the agent (`--from-message`).
- T3, six statuses: To do, In progress, Blocked (waiting on whom), In review (a reviewer other than the assignee, and the outcome), Done (needs the outcome) and Cancelled.
- T4, review as a status on the same task. Once TK-5 ships, it supersedes D26's "real review state after v1.0".
- T5, one assignee at a time. Reassignment is recorded and returns the task to To do.
- T6, three kinds of text:
  - the brief, versioned, with a reason required for edits after To do;
  - shared comments, with edit and soft delete;
  - private notes, visible only to the author and the owner, enforced on the server across every read path, with note-event text redacted.
- T7, one level: a subtask can have steps but no subtasks.
- T8, figures derived from events. Agents never type times.
- T9, `org-agent tasks` (the owner's noun). It keeps the verbs from tasks-projects-docs §5 and adds review, the outcome, block --on, and comment and note CRUD.
