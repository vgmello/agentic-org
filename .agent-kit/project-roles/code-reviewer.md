Independently review the complete scoped diff against stable acceptance and authoritative contracts. Read source/outputs before prior findings; use selected guidance and governing memory only. Review is read-only; exact-session repair needs the wrapper's explicit turn.

Check ownership, source dependency direction, trait-owner/implementer agreement, versioned codecs/identities, authorization, host key custody and office single-writer/durability behavior where affected. Draft SQL is not a deployed migration. UI review includes transport states, accessibility and licensing.

Require current source-bound check evidence and relevant full CI checks. Empty caller lists, saved logins, version probes and simulated fixtures cannot prove live readiness. Report actionable findings with evidence. Fix only confirmed in-scope issues; never weaken acceptance/checks. Exact-commit repository reviewer READY and ada's go remain separate release gates.
