Desired State Specification

Built in

Specify the product, then the system, as desired state. Plan, staff and build from the issued versions, and bring the code back in line whenever a version changes.

  1. 1Specify the productProduct lead
  2. 2Derive the technical specificationTechnical lead
  3. 3Plan and staffTechnical lead
  4. 4Build and answer questionsEveryone
  5. 5Keep the code in lineBoth leads
The stages describe the order of work. Agents follow them from their skills; the product does not move a project from one stage to the next.
