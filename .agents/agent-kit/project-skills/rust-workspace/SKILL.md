description: Implement or review Agentic Org Rust changes with pinned checks, crate ownership and library composition boundaries.

Cargo.toml, rust-toolchain.toml and CI pin Rust 1.99.1, edition 2021 and exact shared dependencies. Read the affected crate's manifest/public API before adding edges. Apps compose libraries; policy contracts stay with their owner. Review public protocol/runtime consumers and update affected trait implementations together. Replace rather than adapt: no migration, compatibility shim, retained protocol version or old name.

For semantic Rust navigation use the existing rust-lsp skill/tool. Report missing access and use compiler/source evidence without claiming typed parity. Repowise is structural discovery; do not install another index.

Run the pinned Rust checks in [DEVELOPMENT.md](../../../DEVELOPMENT.md) from the repository root. CI checks production function length in dev and release, safety documentation and suppression reasons, and workspace tests on macOS and Linux. Use targeted tests during iteration; the host refuses to run as root, so tests run as an ordinary user. Tests use temporary roots. Every operating-system difference lives in crates/org-platform, behind a contract with macOS, Linux and refusing adapters (ADR-0017, docs/design/linux-host.md): no other file gains a cfg, cfg_attr or cfg! on target_os, target_vendor, target_env or target_family, crates/org-platform/tests/platform_conditionals.rs fails on one, and .github/platform-conditionals.allow only shrinks (lower a file's count when it loses predicates). Inspect cancellation, cleanup, errors and idempotency where affected.

Unsafe and lint hygiene: keep new and unsafe-free crates at `#![forbid(unsafe_code)]` (and confine required FFI behind safe adapters or narrow `#[expect(unsafe_code, reason = "...")]` under `#![deny(unsafe_code)]`). Never introduce `unsafe` when `std` or an existing workspace primitive already exists (`std::process::id()`, `org_socket::effective_uid()`, `org_socket::rights::set_buffer_sizes`, `org_proto::zero_bytes`, struct literals or `MaybeUninit` over `mem::zeroed()`). Place `// SAFETY:` directly on every `unsafe` block or its immediately enclosing `let` binding—never above `assert_eq!(unsafe { ... }, ...)` or shared across multiple calls. Use `#[expect(lint, reason = "...")]` for unconditional suppressions (so stale suppressions fail compilation) and `allow(..., reason = "...")` only when a lint fires conditionally across targets or build profiles. Every workspace member must set `[lints] workspace = true`. Verify cross-platform hygiene with `cargo test --locked -p org-platform --test rust_hygiene` and `python3 .agents/agent-kit/runtime/kit_rust_hygiene.py` (both run by `kit_hooks.py check`), and when editing Linux platform adapters on macOS also run `cargo clippy --locked -p org-platform -p org-platform-host --all-targets --all-features --target x86_64-unknown-linux-gnu -- -D warnings`.

Review dependency direction at consistent crate/domain level, downstream callers and failure tests. Agree a contract, credential or durability change that another increment depends on with the other lead before dependent work. Official references on demand: https://doc.rust-lang.org/1.99.1/book/ and https://doc.rust-lang.org/cargo/commands/cargo-test.html . Pinned toolchain/CI remain execution evidence.
